# Screen wireframes

Low-fidelity layouts for the syllabus planner screens. Field names match the API. Grey boxes are inputs. The sample topic is Real Numbers from the bootstrap. Extra rows on coverage and alerts are layout only, so the status colours and the alert columns have something to sit in.

| [Teacher alerts](teacher-alerts.svg) | `/admin/teacher-alerts` | Headmaster, School Admin |
| [Faculty day](faculty-day.svg) | `/faculty/today` | Faculty |
